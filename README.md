# KnotGuide

Free knot tying guide: learn 6 essential knots step by step — bowline, clove hitch, figure-8, sheet bend, taut-line hitch and reef — with clear diagrams.

## Features
- Six-knot library (bowline, clove hitch, figure-8, sheet bend, taut-line, reef) with 4–6 steps each
- Simple SVG line diagrams illustrating each knot's shape
- Difficulty filter (Beginner / Intermediate / Advanced) to learn in the right order
